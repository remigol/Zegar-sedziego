# Zegar Sędziego 1.0

Androidowy zegar meczu piłkarskiego.

## Funkcje
- 00:00 → 45:00, potem osobny licznik `+ MM:SS`
- po zakończeniu doliczonego czasu I połowy: reset dodatkowego czasu i start II połowy od 45:00
- 45:00 → 90:00, potem osobny licznik `+ MM:SS`
- START / STOP
- ręczna edycja czasu MM:SS
- budowanie APK przez GitHub Actions

## GitHub
Wgraj całą zawartość folderu do repozytorium na branch `main`. Workflow `Build Android APK` uruchomi się po pushu lub ręcznie w zakładce Actions. Gotowe APK znajdziesz w Artifacts jako `ZegarSedziego-APK`.
